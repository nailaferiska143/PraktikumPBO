1.	Deskripsi
Program Sistem Perpustakaan Sederhana dibuat menggunakan bahasa pemrograman Java. Program ini digunakan untuk memasukkan dan menampilkan data buku, meliputi judul, penulis, tahun terbit, dan status ketersediaan buku. Dalam class “Buku” yang digunakan untuk menyimpan data buku dan menampilkan informasi buku. Dan pada class “Perpustakaan” berisi program utama untuk menerima input pengguna, memproses data, dan menampilkan hasil.
2.	Tujuan
Program ini dibuat untuk menerapkan beberapa konsep dasar pemrograman Java, yaitu:
a.	Class dan Object
b.	Constructor
c.	ArrayList
d.	Percabangan
e.	Perulangan
f.	Constant
g.	Exception Handling
h.	String dan Character
3.	Fitur
a.	Menambahkan data buku
b.	Menampilkan data buku
c.	Menampilkan status ketersediaan buku
d.	Mengategorikan buku berdasarkan tahun terbit
e.	Menghitung jumlah buku
f.	Menampilkan nama dan kode perpustakaan
g.	Menangani kesalahan input
4.	Konsep Pemrograman yang Digunakan
Program menggunakan class dan object untuk membuat objek buku, constructor untuk menginisialisasi data, ArrayList untuk menyimpan beberapa objek buku, percabangan untuk menentukan kategori buku, perulangan untuk memproses banyak buku, serta exception handling untuk menangani kesalahan input.
